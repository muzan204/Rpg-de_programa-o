# Code Dungeon 4.0 🏰💻

Um RPG de programação em que código vira arma, magia, exploração e progressão.

## 🎮 Visão geral

Você explora uma dungeon digital dividida em reinos de HTML, CSS, JavaScript, SQL e APIs. Para avançar, precisa resolver desafios reais de programação, derrotar bugs, desbloquear habilidades, cumprir quests e preparar seu herói para enfrentar NULL.

## 🌍 Mundos

- 🏛️ Ruínas do HTML
- 🌲 Floresta CSS
- ⚡ Torre JavaScript
- 🗄️ Catacumbas SQL
- 🌐 Reino das APIs

Cada reino agora possui 6 desafios, incluindo uma luta de chefe. O projeto soma 30 missões de código.

## ✨ Sistemas atuais

- XP, níveis, moedas e vidas
- 30 desafios de programação
- Chefões por reino
- Editor de código integrado
- Terminal de resultados
- Progressão e desbloqueio de mundos
- Criação de herói
- Classes: Codemancer, Web Knight e Data Mage
- HP, energia, ataque, defesa e crítico
- Árvore de habilidades
- Habilidades de combate
- Pets digitais
- Quests de campanha
- Missões diárias
- Inventário e relíquias
- Materiais e crafting
- Loja e equipamentos
- Codex de conhecimento
- Dungeon aleatória
- Mentor Javas
- Conquistas
- Salvamento local com LocalStorage
- Interface responsiva para celular e computador

## 🎨 Interface 4.0

A versão 4 usa uma identidade de fantasia tecnológica com azul profundo, azul elétrico, violeta e dourado. A interface possui HUD de combate, navegação rápida, painéis de personagem, árvore de habilidades, pets, quests e Codex.
