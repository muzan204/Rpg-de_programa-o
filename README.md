# Code Dungeon 🏰💻

Um RPG de programação feito para transformar o aprendizado de código em uma aventura.

## 🎮 Sobre o jogo

No Code Dungeon, cada mundo representa uma área da programação. Para avançar, o jogador precisa resolver desafios diretamente no editor de código do jogo.

### Mundos atuais

- 🏛️ Ruínas do HTML
- 🌲 Floresta CSS
- ⚡ Torre JavaScript
- 🗄️ Catacumbas SQL
- 🌐 Reino das APIs

## ✨ Recursos

- Sistema de XP e níveis
- Moedas
- Vidas
- Progresso salvo no navegador com LocalStorage
- Mundos desbloqueáveis
- 10 desafios de programação
- Mentor Javas com dicas
- Conquistas
- Editor de código integrado
- Terminal de resultados
- Design dark/cyber responsivo
- Compatível com celular e computador

## 🚀 Como executar

Você pode abrir o arquivo `index.html` diretamente no navegador.

Para desenvolvimento local, também pode usar qualquer servidor estático, como Live Server do VS Code.

## 🧠 Tecnologias

- HTML5
- CSS3
- JavaScript puro
- LocalStorage
